# ПроСтиль — публикация на Netlify

## Что исправлено
- Next.js собирается командой `npm run build` (без отсутствующих scripts).
- API `/api/bookings` вместо Cloudflare D1 хранит заявки в **Netlify Blobs**.
- Администратор по-прежнему просматривает заявки по `/admin`, обновляет статусы, использует тот же секретный ключ.
- Уведомления в Telegram доступны после настройки переменных.

## Как обновить GitHub
1. Распакуйте архив.
2. Замените **содержимое** репозитория `prostil-website` файлами из папки проекта (старые файлы не удаляйте без необходимости).
3. Не добавляйте `.git`, `.next`, `node_modules`, `.env` и токены в GitHub.
4. В GitHub Desktop: Commit to main → Push origin.

## Настройки Netlify
- Framework: Next.js; Build command: `npm run build`; Publish directory: `.next`.
- В разделе Project configuration → Environment variables создайте `ADMIN_KEY`: уникальный случайный секрет длиной не меньше 16 символов (лучше 32+). НЕ добавляйте его в GitHub.
- По желанию: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для уведомлений. Без них заявки всё равно сохраняются.
- Environment variables должны быть доступны в runtime Functions, затем запустите новый Deploy.
- После публикации зайдите на `https://ВАШ_САЙТ.netlify.app/admin` и введите `ADMIN_KEY`.

## Проверка
Отправьте тестовую заявку с публичного сайта → должна появиться в `/admin` → измените статус. Если сервер вернёт 503, проверьте переменную `ADMIN_KEY`. Если вернёт 500, смотрите Function logs в Netlify.

## Ограничение
Netlify Blobs — хранилище ключ/значение, подходит для небольшого потока заявок; это не полноценная транзакционная CRM-база. При большом трафике, высокой конкуренции запросов и сложной аналитике потребуется Netlify DB/Postgres. Лимит частоты заявок основан на последовательной проверке и может допустить одновременные заявки. Данные клиентов обрабатывайте в соответствии с требованиями к защите персональных данных.

**Проверка:** локальный npm install в этой среде не завершился из-за недоступности/таймаута реестра; окончательная проверка сборки выполняется Netlify при deploy. Никаких заявок на публичном сайте ещё не тестировали.
