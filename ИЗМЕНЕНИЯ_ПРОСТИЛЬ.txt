ПРОСТИЛЬ — ИСПРАВЛЕНИЯ САЙТА
===================================

ОСНОВНОЕ
• Бренд «ПроСтиль» уже присутствовал в большинстве исходных файлов
  загруженной версии. Он сохранён в меню, первом экране, прайсе,
  формах, админ-панели, SEO-заголовках и политике данных.
• Переработаны SVG-контуры интерактивной схемы оклейки BMW M5 F90:
  капот, передний бампер, переднее крыло, зеркала, пороги, ручки,
  передняя и задняя двери, крыша, передние стойки.
• Вместо одновременного показа всех красных контуров подсвечивается
  только выбранная зона. Выбор работает через кликабельные маркеры,
  саму зону и кнопки справа. Дизайн сайта и другие анимации сохранены.
• Для SEO-адреса сайта можно задать переменную NEXT_PUBLIC_SITE_URL
  (на Netlify допускается также встроенная переменная URL).

ИЗМЕНЁННЫЕ ФАЙЛЫ
app/protection-zones.ts
app/refinement.css
app/data.ts

КАК ПРИМЕНИТЬ ПАТЧ
1. Сделайте резервную копию своего проекта.
2. Распакуйте ZIP-архив «только изменения» в корень исходного проекта,
   подтвердите замену трёх файлов из списка выше.
3. Соберите и опубликуйте сайт заново через вашу существующую систему
   сборки и деплоя. Простого обновления браузера недостаточно.
4. Если появился новый официальный домен студии, укажите его адрес
   в NEXT_PUBLIC_SITE_URL до сборки: например https://ВАШ-ДОМЕН.ru.

ВАЖНО
• Ссылка Instagram с именем wrapstudionsk сохранена намеренно:
  это действительный предоставленный аккаунт, не текстовый логотип.
• Сохраняется технический адрес предпросмотра, если ни NEXT_PUBLIC_SITE_URL,
  ни URL не заданы. Его нужно заменить на официальный домен для SEO.
• Логотип «ПроСтиль» в архиве не предоставлен; на сайте используется
  текстовое название. Реальный логотип можно подключить позднее.
• Контуры привязаны к файлу public/images/hero.webp; при замене
  фотографии их необходимо перенастраивать.
• Полноценная сборка и работа API заявок в реальном хостинге не
  проверялись: для них нужны зависимости и среда развертывания.
